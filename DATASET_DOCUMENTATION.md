# Dataset Documentation
## Multimodal Deepfake Detection and Explainable Content Verification

## 1. Overview

This project uses image-caption pairs to study multimodal classification. The objective is to identify whether an image and its associated caption are semantically consistent.

The project contains two dataset-related components:

1. A small synthetic test dataset used for initial pipeline testing and debugging.
2. A Fakeddit binary subset used in the team's experimental comparison and statistical analysis.

These datasets serve different purposes and should not be treated as interchangeable.

## 2. Synthetic Test Dataset

### 2.1 Purpose

The synthetic dataset was created to test the project's data-loading, image preprocessing, validation, and evaluation pipeline.

It contains 10 computer-generated image-caption pairs.

### 2.2 Dataset Structure

Location: `data/small_test_dataset/`

```text
small_test_dataset/
│
├── test_dataset.csv
├── README.txt
├── create_images.py
├── dataset_loader.py
├── validate_dataset.py
│
└── images/
    ├── beach.png
    ├── car.png
    ├── dog.png
    ├── mountain.png
    └── soccer.png
```

### 2.3 Dataset Distribution

| Property | Value |
|---|---:|
| Total samples | 10 |
| REAL samples | 5 |
| FAKE samples | 5 |
| Categories | 5 |
| Samples per category | 2 |
| Image format | PNG |

### 2.4 Categories

The dataset contains the following categories:

- Beach
- Soccer
- Mountain
- Dog
- Car

Each category contains one matching image-caption pair and one mismatched image-caption pair.

### 2.5 Label Mapping

| Label | Class | Meaning |
|---|---|---|
| 0 | FAKE | Image and caption do not match |
| 1 | REAL | Image and caption match |

Here, FAKE refers to an image-caption mismatch. It does not necessarily mean that the image was synthetically generated or manipulated.

### 2.6 Validation

The pilot dataset was validated using Python scripts.

The validation confirmed:

- All 10 records loaded successfully.
- All referenced image paths were found.
- No images were missing.
- All labels were valid (0 or 1).
- Both classes had equal representation.

### 2.7 Limitations

- The dataset contains only 10 samples.
- Images are computer-generated illustrations.
- Its small size is insufficient for reliable model training.
- It cannot support research-level performance claims.
- It does not represent the diversity of real-world images and captions.

Therefore, it is intended only for initial pipeline testing and debugging.

## 3. Fakeddit Binary Subset

### 3.1 Purpose

The team's experimental comparison uses a binary subset of the Fakeddit dataset.

Fakeddit is a multimodal fake-news dataset. In this project, the binary subset is used to study classification using image and text information.

### 3.2 Experimental Dataset Details

According to the existing experimental report:

| Property | Value |
|---|---|
| Dataset | Fakeddit binary subset |
| Test samples | 400 |
| Classes | 2 |
| Class labels | FAKE (0), REAL (1) |
| Evaluation method | Test-set evaluation |
| Seed selection | Highest validation Macro-F1 |

The full dataset size and exact train-validation-test split are not specified in the available experimental report.

### 3.3 Label Mapping

| Label | Class |
|---|---|
| 0 | FAKE |
| 1 | REAL |

The project uses image-caption consistency as its classification interpretation. This should not be confused with detecting whether an image or video was generated by AI.

### 3.4 Experimental Models

The existing report compares these approaches:

1. DistilBERT fine-tuned
2. Frozen text-only
3. Frozen image-only
4. Concatenation
5. Concatenation with CLIP similarity
6. Cross-attention
7. Cross-attention with CLIP similarity
8. Late fusion

### 3.5 Reported Experimental Results

The following results are taken from `results/part9/report.md`.

| Model | Accuracy | Macro-F1 | ROC-AUC |
|---|---:|---:|---:|
| DistilBERT fine-tuned | 75.50% | 0.7549 | 0.8347 |
| Frozen text-only | 73.25% | 0.7319 | 0.8374 |
| Frozen image-only | 77.50% | 0.7749 | 0.8535 |
| Concatenation | 80.50% | 0.8050 | 0.8924 |
| Concatenation + CLIP similarity | 78.25% | 0.7824 | 0.8806 |
| Cross-attention | 75.50% | 0.7541 | 0.8442 |
| Cross-attention + CLIP similarity | 79.25% | 0.7922 | 0.8667 |
| Late fusion | **83.00%** | **0.8300** | 0.8913 |

Late fusion achieved the highest reported accuracy and Macro-F1 among these models.

These results belong to the team's reported experiment and are separate from the synthetic pilot dataset validation.

### 3.6 Statistical Analysis

The experimental report includes:

- 95% stratified bootstrap confidence intervals.
- Exact two-sided McNemar tests for paired model comparisons.
- Holm correction for multiple comparisons.
- Complementarity analysis between model predictions.
- Disagreement analysis between the DistilBERT baseline and late fusion.

These methods help assess uncertainty and compare model performance.

## 4. Dataset Usage in the Project

| Dataset component | Main purpose |
|---|---|
| Synthetic test dataset | Test loading, preprocessing, validation and evaluation |
| Fakeddit binary subset | Experimental model comparison and performance evaluation |

The synthetic dataset is useful for checking whether the pipeline works. The Fakeddit subset is used for the team's reported model experiments.

## 5. Limitations and Future Work

### Limitations

- The synthetic pilot is too small for meaningful model training or benchmarking.
- The full Fakeddit dataset and its complete split details are not present in the available local dataset directory.
- The experimental report specifies 400 test samples but does not document the complete dataset distribution.
- Image-caption mismatch classification does not establish whether an image or video is AI-generated or manipulated.
- Category-wise generalization requires sufficient category-labelled evaluation data.

### Future Work

- Expand testing with larger and more diverse real-world image-caption datasets.
- Document the exact training, validation and test splits.
- Evaluate performance across different categories.
- Conduct image and text corruption robustness experiments.
- Integrate the final multimodal model and perform actual end-to-end evaluation.
- Report limitations and confidence intervals alongside performance metrics.

## 6. Conclusion

The project uses a small synthetic dataset for pipeline validation and a Fakeddit binary subset for experimental evaluation.

Keeping these purposes separate ensures that pipeline testing results are not mistaken for research-level model performance. Further evaluation with the integrated multimodal model and larger datasets is necessary to establish real-world performance.
